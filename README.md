# MisinformationChatDeleter
In recent times, misinformation has been spread through social media and text messages.
My new chat application fact checks whether a text message is misinformation.
If it is misinformation, then it rates it on how far the misinformation is.
If it is above 9, then the message is blocked.
If it is over 5, then the messsage is tagged as probable misinformation
This will help stop misinformation.

# Frameworks Machine Learning
Because to fact check whether the misinformation is misinformation, I can not use pytorch or train a model on that, because that would require constant updates on the data and a large data base. Because of this, I will be using openai. 
#Frame works for Web dev
I will be using flask for simpilcity, and AJAX for sending and recieving messages.

# How to run
1. Install python
2. Install flask, openai, and get yourself an openai api key.
3. After that, then download the code.
4. Run it on local host and see the website.
5. If you want to host it, you can; this is an open source project to try and stop misinformation in the world.
